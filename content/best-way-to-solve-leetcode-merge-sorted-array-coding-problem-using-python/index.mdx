Merging sorted arrays efficiently is a crucial operation in various programming scenarios. In this blog, we'll delve into a Python implementation of merging two sorted arrays and analyze its time complexity. Through the use of docstrings and classes, we'll ensure clarity and reusability.

## Problem Statement

You are given two integer arrays nums1 and nums2, sorted in non-decreasing order, and two integers m and n, representing the number of elements in nums1 and nums2 respectively.

Merge nums1 and nums2 into a single array sorted in non-decreasing order.

The final sorted array should not be returned by the function, but instead be stored inside the array nums1. To accommodate this, nums1 has a length of m + n, where the first m elements denote the elements that should be merged, and the last n elements are set to 0 and should be ignored. nums2 has a length of n.

## Example

Example 1:

Input: nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3
Output: [1,2,2,3,5,6]
Explanation: The arrays we are merging are [1,2,3] and [2,5,6].
The result of the merge is [1,2,2,3,5,6] with the underlined elements coming from nums1.

Example 2:

Input: nums1 = [1], m = 1, nums2 = [], n = 0
Output: [1]
Explanation: The arrays we are merging are [1] and [].
The result of the merge is [1].

Example 3:

Input: nums1 = [0], m = 0, nums2 = [1], n = 1
Output: [1]
Explanation: The arrays we are merging are [] and [1].
The result of the merge is [1].
Note that because m = 0, there are no elements in nums1. The 0 is only there to ensure the merge result can fit in nums1.


## Approach

We'll implement a function called merge that takes four parameters: nums1, m, nums2, and n, where:

- nums1 is the first sorted array with extra space at the end to accommodate nums2.
- m is the number of elements in nums1.
- nums2 is the second sorted array.
- n is the number of elements in nums2.

## Code
```python title="Code" caption="python"
class Solution:
    def merge(nums1, m, nums2, n):
        """
        Merges two sorted arrays in-place.

        Parameters:
        - nums1: First sorted array with extra space.
        - m: Number of elements in nums1.
        - nums2: Second sorted array.
        - n: Number of elements in nums2.
        """

        # Iterate through nums2
        for j in range(n):
            # Place each element of nums2 at the end of nums1
            nums1[m + j] = nums2[j]
        
        # Sort the merged array
        nums1.sort()


nums1 = [1, 2, 3, 0, 0, 0] # Example usage
m = 3
nums2 = [2, 5, 6]
n = 3

Solution.merge(nums1, m, nums2, n) # Merge nums2 into nums1

print(nums1)  # Output: [1, 2, 2, 3, 5, 6] # Output the merged and sorted array
```

### Time Complexity
The time complexity of the provided code is primarily determined by the sorting operation, which is typically O(n log n), where n is the total number of elements in both arrays nums1 and nums2.

### Space Complexity
The space complexity of the code is O(1) since the merging is done in-place, and no additional data structures are used. However, the sort() method might internally use extra space for its operations, but this is usually negligible compared to the input size.
