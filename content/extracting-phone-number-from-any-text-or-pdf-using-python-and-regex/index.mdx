During this era of technology, one is usually required to get useful information out of text materials or digital files. One way of doing this is to get all possible phone numbers out of the text songs in different formats like TXT, PDF among others. Therefore, let’s discuss how we can use python with regular expressions in order to extract either all or some telephone numbers which may exist in our given text document or even an Adobe Acrobat form.

## Why Use Regex for Phone Number Extraction?
Regular concentrations constitute a dominant device for text manipulation and matching of patterns. They offer the ability to create search patterns which got an ability of recognizing diverse formats of phone numbers making them perfect for such a need.

## Understanding the Regex Pattern
To capture phone numbers in different formats, we need a comprehensive regex pattern. Here’s the regex we'll use:

```python title="regex pattern" caption="regex pattern"
(\+?\d{1,3}[\s-]?)?(\(?\d{3}\)?[\s-]?)?\d{3}[\s-]?\d{4}
```

## Breakdown of the Pattern
- (\+?\d{1,3}[\s-]?)?: Matches an optional country code, which can start with a "+" and be followed by 1 to 3 digits, optionally followed by a space or a hyphen.
- (\(?\d{3}\)?[\s-]?)?: Matches an optional area code, which can be enclosed in parentheses and be followed by a space or a hyphen.
- \d{3}[\s-]?\d{4}: Matches the local number part, which consists of three digits followed by a space or a hyphen, and then four digits.


## Extracting Phone Numbers from Text
Let's start with a simple example to extract phone numbers from a block of text.

```python title="python code" caption="python code"
import re

def extract_phone_numbers(text):
    phone_pattern = re.compile(r'(\+?\d{1,3}[\s-]?)?(\(?\d{3}\)?[\s-]?)?\d{3}[\s-]?\d{4}')
    return phone_pattern.findall(text)

text = """                 
Call me at (123) 456-7890 or at 123-456-7890. My office number is +1 123 456 7890.
You can also reach me at +91-9876543210 or (987) 654-3210.
"""                                                                  # Example text

phone_numbers = extract_phone_numbers(text)   # Extract phone numbers
print(phone_numbers)
```

### Output
This script will output a list of phone numbers found in the text:

```python title="output" caption="output"
[('(123) ', '456-7890'), ('123-', '456-7890'), ('+1 ', '123 456 7890'), ('+91-', '9876543210'), ('(987) ', '654-3210')]
```

## Extracting Phone Numbers from PDF

To extract phone numbers from a PDF, we need to first read the content of the PDF. We can use libraries like PyPDF2 or pdfminer.six for this purpose. In this example, we'll use PyPDF2.

### Extracting Text from PDF and Finding Phone Numbers

```python title="python code" caption="python code"

import re
import PyPDF2

def extract_text_from_pdf(pdf_path):
    with open(pdf_path, 'rb') as file:
        reader = PyPDF2.PdfFileReader(file)
        text = ''
        for page_num in range(reader.getNumPages()):
            page = reader.getPage(page_num)
            text += page.extractText()
    return text

def extract_phone_numbers(text):
    phone_pattern = re.compile(r'(\+?\d{1,3}[\s-]?)?(\(?\d{3}\)?[\s-]?)?\d{3}[\s-]?\d{4}')
    return phone_pattern.findall(text)

pdf_path = 'path/to/your/pdf/file.pdf'       # Path to your PDF file


pdf_text = extract_text_from_pdf(pdf_path)     # Extract text from PDF

phone_numbers = extract_phone_numbers(pdf_text)     # Extract phone numbers
print(phone_numbers)
```
