The Two Sum problem is a classic algorithmic problem where we are given an array of integers and a target integer, and we need to find two numbers in the array that add up to the target. In this blog post, we'll explore an efficient solution to this problem using Python.


## Problem Statement
Given an integer array nums sorted in non-decreasing order, remove the duplicates in-place such that each unique element appears only once. The relative order of the elements should be kept the same. Then return the number of unique elements in nums.

Consider the number of unique elements of nums to be k, to get accepted, you need to do the following things:

Change the array nums such that the first k elements of nums contain the unique elements in the order they were present in nums initially. The remaining elements of nums are not important as well as the size of nums.
Return k.

## Approach 1: Using a set
```python title="Approch 1" caption="python"
class Solution:
    def removeDuplicates(self, nums) -> int:
        """
        Removes duplicates from a sorted array using a set.

        Parameters:
        - nums: A sorted list of integers with possible duplicates.

        Returns:
        - int: The new length of the array after removing duplicates.
        """

        # Initialize a set to store unique elements
        unique_set = set()
        
        # Initialize index to keep track of unique elements
        unique_index = 0
        
        # Iterate through the array
        for num in nums:
            # If the element is not in the set, it's unique
            if num not in unique_set:
                unique_set.add(num)  # Add the element to the set
                nums[unique_index] = num  # Update the array with the unique element
                unique_index += 1  # Increment the unique index
        
        return unique_index

nums = [0, 0, 1, 1, 1, 2, 2, 3, 3, 4] # Example usage
sol = Solution()
new_length = sol.removeDuplicates(nums)
print("New Length:", new_length)
print("Modified Array:", nums[:new_length])
```

### Time Complexity
- Approach 1: In this approach, we iterate through the array once and perform constant time operations for set membership check and insertion. Hence, the time complexity is O(n), where n is the length of the array.
### Space Complexity
- Approach 1: We use a set to store unique elements encountered in the array. The space complexity of this approach is O(n) in the worst-case scenario where all elements are unique.


## Approach 2: Using Two Pointers
```python title="Approach 2" caption="python"
class Solution:
    def removeDuplicates(self, nums) -> int:
        """
        Removes duplicates from a sorted array using two pointers.

        Parameters:
        - nums: A sorted list of integers with possible duplicates.

        Returns:
        - int: The new length of the array after removing duplicates.
        """

        # Initialize the second pointer
        j = 1
        
        # Iterate through the array starting from the second element
        for i in range(1, len(nums)):
            # If the current element is different from the previous one
            if nums[i] != nums[i - 1]:
                # Move the unique element to the current position indicated by the second pointer
                nums[j] = nums[i]
                # Move the second pointer forward
                j += 1
        
        return j

nums = [0, 0, 1, 1, 1, 2, 2, 3, 3, 4] # Example usage
sol = Solution()
new_length = sol.removeDuplicates(nums)
print("New Length:", new_length)
print("Modified Array:", nums[:new_length])
```


### Time Complexity
- Approach 2: This approach also iterates through the array once. Inside the loop, we perform constant time operations such as array element comparison and assignment. Therefore, the time complexity is also O(n).
### Space Complexity
- Approach 2: This approach modifies the array in-place without using any additional data structures. Thus, it has a space complexity of O(1), making it more memory-efficient.

## Conclusion
Both approaches offer efficient solutions to the problem of removing duplicates from a sorted array. However, they differ in terms of space complexity.

- Approach 1 is straightforward and easy to implement but consumes additional space proportional to the number of unique elements.
- Approach 2 is more memory-efficient as it operates in-place without using extra space, making it preferable for scenarios where memory consumption is a concern.
